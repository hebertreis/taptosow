Setup Instructions

Required Configuration:

1. Set Stripe Secret Key in Firebase:
    firebase functions:config:set stripe.secret_key="sk_test_YOUR_KEY"

2. Set Publishable Key for the frontend (root .env):
    STRIPE_PUBLIC_KEY=pk_test_YOUR_PUBLISHABLE_KEY_HERE
    Note: The dev server exposes `STRIPE_PUBLIC_KEY` to the client (via vite envPrefix).

3. Deploy Functions:
    firebase deploy --only functions

4. Deploy Hosting:
    firebase deploy --only hosting
